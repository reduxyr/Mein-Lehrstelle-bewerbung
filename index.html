Bestellbestätigungen als Nachweis

Eigener Garry's Mod Server

Ich habe einen eigenen Garry's Mod Server eingerichtet und konfiguriert — den «Metrostroi»-Server, ein Sandbox-Gamemode rund um eine Moskauer-Metro-Simulation.

Dadurch konnte ich erste Erfahrungen mit Servern, Konfigurationen und der selbstständigen Fehlersuche sammeln. Ich habe den Server über die Kommandozeile mit eigenen Startparametern konfiguriert (z. B. maxplayers, Gamemode, Karte und eine eigene Workshop-Addon-Collection für automatisches Herunterladen der Mods).

Besonders gefällt mir, dass man bei technischen Problemen selbst nach einer Lösung suchen und dabei immer etwas Neues lernen kann — zum Beispiel beim Beheben von fehlgeschlagenen Addon-Downloads oder unbekannten Konfigurationsbefehlen.
